# BrainWorkflow 操作指南

## 打开与启动

双击工作区根目录 `BrainWorkflow.cmd` 或 `BrainWorkflow.vbs`，打开桌面应用。
不需要启动终端或手动刷新网页。当前安装版本及验收见根 `todo.md`。

1. 选择研究 Option Card。Multiplier 由你选择 Region、Delay 和有效 Universe；倍率适用条件由你判断。
2. 点击 **Start**。后台直接使用当前知识库；新 Multiplier 范围没有本地字段时，在已授权边界内采集并编译。
3. 使用左右箭头和 `1/N` 查看各路研究；树节点、Scout / Seed / Repair 标签仅用于查看，不是推进按钮。
4. 点击 **Stop** 暂停；之后 **Start / Resume** 继续原有任务，不创建替代任务或提高上限。

源代码存在不等于应用已经更新；维护流程会构建、验收、安装同一点击入口。

## 自动执行什么

AI 每一路在最前面进行一次受限规划任务，按需检索 raw、machine 和 wiki，
提出经济假设、数据特性和完整实验树。它可以在该任务内使用本地校验工具修正草案。
程序检查 Schema、AST、类型、算符签名、范围及实验树，再由脚本封装执行包。

之后脚本回测、判断分支、必要时回退、选择 Seed、执行有限 Repair、检查和记录候选。
研究中途不调用模型补分支或猜公式。Repair 保持原逻辑，每次改变一个因素，接受、回退或穷尽有限规则。
数据含义、频率、覆盖率等未知项保持未知，不伪装成事实；未知经济语义、资料年龄和覆盖率不是知识库准入门槛。
不支持的类型、调用和实验结构仍会明确拒绝。

## 查看进度与问题

时间线显示阶段和当前动作；策略列表显示表达式、在途状态、Alpha ID、指标和检查结果。
初始规划显示检索、验证和模型任务状态。模型由本地 Codex worker 调用，
不保证本维护聊天会出现新的模型回复；运行事实在应用和持久化任务中。

限流、轮询和可恢复故障由脚本有界处理；无法自动处理时记录原因和证据，并投递维护消息。
通知送达不是自动改码授权。Stop 优先于回调、重试和重启，未知 POST 不会盲目重新提交。
平台外部故障或受保护决策可能使任务暂停，应用应显示具体原因，不能声称已成功。

## 预算与提交

共享每日 4,000 次 simulation 尝试，按北京时间零点重置；multisimulation 按子策略计数。
GET 不扣次数，失败或未知 POST 不退款；跨天不延长时长，也不会取消 Stop。
时长和恢复次数上限独立，变更需要明确授权。

先完成基础指标检查，再检查 SELF/PROD correlation。只有完整有效检查通过的候选才入库。
合格但未提交的 Alpha ID 和证据保留，避免无效重复检查；最终提交须另行明确授权具体 Alpha ID。

## 知识维护与空间

平台资料更新是独立维护请求，除新版 Multiplier 的受限按需字段准备外，不隐式联网抓取。
本地维护只更新当前资源、唯一可重建索引及可复用经验，不重复保存整库库存或巨型报告。
完成的执行包在结果和必要摘要持久化后退役；暂停或尚有未决任务时不能退役。
本次授权已清理旧运行，不能再恢复这些历史任务；配额、去重和必要候选事实不因此清零。
存储边界见 [product-storage.md](product-storage.md)，工具链见 [workflow-toolchain-map.md](workflow-toolchain-map.md)。
