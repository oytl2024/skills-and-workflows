## First Increment: Technical Tools

CNHK4.3.17 contains copied platform operator definitions for logical function
calls and lowercase booleans,and examples of conditional comparisons. They are
publisher snapshots,not proof of current account-wide signature coverage.
Fix Python-specific parsing/rendering incompatibilities without evaluating code:
and/or/not named calls;true/false literals;single binary comparisons in structural
ASTs. Preserve strings verbatim and reject Python attributes,subscripting,lambdas,
comprehensions and arbitrary statements. Unsupported constructs report capability
diagnostics,not a fabricated platform rejection. Known types remain checked;
unknown operator signatures stay unknown and exploratory in the approved mode.
Repair must parse and reproduce these expressions using the same tools.

Public finite local grammar is testable;universal platform correctness is not
claimed. Full statement syntax/ternaries/variadic signature semantics are separate
capabilities to implement only with evidence and an explicit contract.
