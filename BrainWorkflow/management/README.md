# Retired Project Board

The project board is retired. `Open Board.cmd` and the legacy Python entry only report retirement; they do not launch desktop processes, start the architecture viewer, access the network or change research state.

Research still uses workspace `BrainWorkflow.vbs` or the product desktop launchers. Maintenance and AI routing use the workspace-root `AGENTS.md`, `milestone.md` and `todo.md`, with `wqb/project_architecture.py` validating the canonical architecture tables. These are not board-only assets.

This directory is pending audited removal, not an active management interface. The parent maintenance loop owns the cleanup audit, verified commit/push ordering and actual deletion. Existing cards, screenshots and desktop profiles remain untouched until that audit is accepted. Profiles may contain cookies, tokens, local paths or other private data: do not print their contents, upload them for backup or assume Git can restore them. Unexpected installed-app subdirectories and untracked evidence need separate classification before recursive cleanup.
