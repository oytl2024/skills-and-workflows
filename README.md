# skills-and-workflows

个人可复用 skills 与工作流仓库。

## Skills

| Skill | 路径 | 用途 |
| --- | --- | --- |
| glimpse | `.agents/skills/glimpse/` | 将政策、资料、市场信息整理成带来源的 Markdown；如需要 HTML，必须先完成 Markdown，再生成可点击知识导图。 |

## Glimpse

`glimpse` 包含两个子流程：

- `glimpse-md`：生成通俗、带来源、可用于 Obsidian 的 Markdown 讲义。
- `glimpse-html`：在已有 `.md` 逻辑基础上，生成本地可点击 HTML 知识导图。

规则：做 HTML 前必须先有 Markdown。
