# Output Contract

## Per-chapter file

每章默认输出：

```text
第NN章知识点与考点.md
```

默认结构：

```markdown
# 第NN章知识点与考点

## 一、本章知识点

### 知识点1：...
...

## 二、本章考点

### 考点1：...
#### 1. 题目怎么考
#### 2. 模型假设
#### 3. 数学表达
#### 4. 变量定义
#### 5. 推导起点
#### 6. 图形分析
#### 7. 传导链条
#### 8. 为什么这样变化
#### 9. 易错点
#### 10. 标准作答模板

## 三、本章知识逻辑链

### 1. 本章先修知识
### 2. 本章内部主链条
### 3. 与前后章节的连接
### 4. 建议学习顺序

## 四、结合题目讲解
```

## Knowledge logic chain

这一部分至少要把知识点用箭头串起来，而不是重新罗列标题。

优先使用：

```text
定义 -> 公式 -> 图形 -> 机制 -> 题型
```

当模型关系复杂时，可以追加 Mermaid，例如：

```mermaid
flowchart LR
  A["名义汇率"] --> B["实际汇率"]
  B --> C["竞争力判断"]
  C --> D["题型判断"]
```

## Course-level map

课程级总文件默认命名：

```text
<课程名>知识逻辑地图.md
```

默认结构：

```markdown
# <课程名>知识逻辑地图

## 一、课程总主线
## 二、章节依赖关系
## 三、跨章核心模型连接
## 四、从零开始的最短学习路径
## 五、考前速过路径
## 六、题目反查入口（若有题目材料）
```

## Optional reverse index

若题目材料足够丰富，建议额外生成：

```text
<课程名>题目-知识点反查表.md
```

推荐结构：

```markdown
# <课程名>题目-知识点反查表

## 按章节反查
## 按题型反查
## 按知识点反查
```
