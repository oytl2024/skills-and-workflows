# Student Quality Bar

## Core standard

假设用户是学生，而且希望：

- 学得比看教材更快
- 理解比看教材更深
- 复习时不必反复翻 PPT 和作业

因此，输出质量必须高于普通摘要。

## What makes students stop needing the textbook

### 1. Every chapter must answer three questions

- 这是什么
- 为什么是这样
- 考试怎么考、怎么答

### 2. No step-skipping

如果一个结论依赖：

- 某个定义
- 某个假设
- 某个公式
- 某个图形关系

就必须把依赖链写出来。

### 3. Teach the mechanism, not just the result

不能只写：

```text
利率上升，本币升值
```

必须写：

```text
利率上升
-> 本币资产收益率提高
-> 资本流入增加
-> 外汇供给增加
-> 本币升值
```

### 4. Teach the exam form, not just the knowledge point

每个高频考点要说明：

- 题目通常怎么设问
- 出题人喜欢怎么变形
- 写答案时哪几步不能漏

### 5. Build an internal map for the student

学生不是最缺知识点，而是最缺“路线图”。因此输出中要主动补：

- 本章主线
- 章节之间的连接
- 从零开始的学习顺序
- 考前压缩复习路径

### 6. Add an error-prevention layer

高分讲义必须告诉学生：

- 最容易错在哪里
- 为什么会错
- 如何快速自检

### 7. Add a reverse index

如果题目材料充足，增加：

- 题目 -> 知识点
- 知识点 -> 题型
- 题型 -> 标准答案框架

学生做错题后，就能反查薄弱点，而不是回去盲翻教材。

## Recommended extras

如果材料足够，优先追加这些内容：

- `常见误区`
- `一小时速过路径`
- `三小时冲刺路径`
- `考前最后核对清单`

这些不是花哨附件，而是最贴近学生真实使用场景的部分。
